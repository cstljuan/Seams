# How to use Seams

Install Node.js, then run `npm install` and `npm run dev`. Open the local address printed by Next.js. The initial map uses Sperry's sample projects and the OpenFreeMap Positron basemap.

The right panel is a layout placeholder while the search, filters, overlap ranking, and details are built. The project markers distinguish DESC and GPC with the theme utility colors.
