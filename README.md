# Seams

Seams maps planned electric utility projects and highlights nearby work that could be coordinated.
It helps teams spot shared outage windows, access, logistics, crews, and equipment opportunities.

## Getting started

Install Node.js, run `npm install`, then `npm run dev` and open the local URL. `npm run build` creates a production build; `npm test` runs the fixture checks.

## Data sources

- Sperry Tech GridLock sample package
- Utility filings
- OpenStreetMap

## Assumptions and limits

The included points and six overlap examples are challenge sample data. Distances are approximate unless both projects have real line geometry from OpenStreetMap. Cost figures are estimates and must be shown as ranges. The app reads the fixtures for now. Overlaps are not calculated yet.
