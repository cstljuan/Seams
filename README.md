ShellHacks 2026 project. Hacking ends Sunday Sept 27, 11:00 AM EDT.

## How we work

- This repo is code only: source, tests, configs, package manifests, plus `README.md`, `AGENTS.md`, and `CLAUDE.md`. Research, notes, and vault content live outside the repo and are never committed here.
- Everyone works on their own branch, named `<your-github-username>/<topic>`.
- Changes land through small pull requests, reviewed and merged by a human. No direct pushes to `main`.
- Coding agents (Codex, Claude Code, etc.) follow the rules in [AGENTS.md](./AGENTS.md).
- One shared brain: the team's research and notes live in Juan's Obsidian vault, not in this repo. Ask in Discord and Axiom (the team bot) will answer from the vault.
