# Data scripts

`us-towns-geonames.csv` is every populated place of 1,000 people or more in the lower 48 states (16,973 towns), trimmed to name, state, population and coordinates from the GeoNames `cities1000` export (https://www.geonames.org, CC BY 4.0). It anchors the illustrative dataset to real places across every state, not just big metros.

Alex owns this folder. Add data extraction, geocoding, and import scripts here. Store generated project and overlap data in `data/` and follow `docs/data-contract.md`.
