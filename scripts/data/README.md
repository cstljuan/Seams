# Data scripts

`us-cities-top-1k.csv` is the 1,000 largest US cities with population and coordinates, from the public plotly/datasets repository (https://github.com/plotly/datasets, `us-cities-top-1k.csv`). It anchors the illustrative dataset to real places.

Alex owns this folder. Add data extraction, geocoding, and import scripts here. Store generated project and overlap data in `data/` and follow `docs/data-contract.md`.
